# MYP Design Portfolio Website

A free, static, student-friendly MYP Design portfolio template.

## Files
- index.html — complete website
- style.css — responsive styling
- script.js — small mobile navigation interaction

## How to use for free
1. Open `index.html` in a browser to preview it.
2. Replace "Student Name", school, unit, global context and statement of inquiry.
3. Replace each 📌 placeholder with your own evidence, images, links, reflections and documents.
4. For free online hosting, upload the three files to GitHub Pages or another free static-hosting service.

## Suggested evidence
Criterion A: problem statement, research questions, surveys, interviews, product analysis, design brief.
Criterion B: specifications, sketches, annotations, selected idea, technical drawings.
Criterion C: timeline, process photos, technical skills, prototype/final product, changes.
Criterion D: testing plan, results, user feedback, evaluation, impact, improvements.

Note: The strand wording/clarifications are presented as student-friendly portfolio prompts. Match them to your school's exact MYP task-specific clarification and assessment language before formal submission.
